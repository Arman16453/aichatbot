# AI-based Help Bot for Information Retrieval from Web Content

## Problem Details
- **Problem ID**: PS000007
- **Name of Industry**: Space Applications Centre ISRO
- **Users**: Citizens, agencies and end users

## Problem Statement
AI based Help Bot for information retrieval out of web content.

## Description of the Problem
### Overview
Automated information Retrieval: The bot will continuously scan and index content from the website to ensure up to date information. Natural Language Understanding (NLU): Users can interact with the bot using natural language queries, making information retrieval intuitive. Context Awareness: The bot will retain previous interactions within a session to provide relevant follow-ups and learning capabilities. Over time, the bot will refine its responses based on user interactions and feedback.

### Background
MOSDAC (www.mosdac.gov.in) portal hosts satellite data and services that are available freely to the citizens. It hosts vast amounts of information, including FAQs, documentation, product details, and support materials. However, users often struggle to find the specific information they need due to navigation, mixed content, or time constraints. Manually searching for relevant details can be inefficient and frustrating.

### Solution Requirements
The AI-based help bot will be an intelligent virtual assistant designed to extract, process, and present relevant information from the website. The bot will leverage:
- Natural Language Processing (NLP)
- Machine Learning (ML) techniques
- Understanding of user queries
- Accurate responses based on information already hosted on web

### Type of Information to Process
- Documents
- Static content
- Web pages
- Tables
- Meta tags
- Grid-labels etc.

## Objective
To utilise maximum out of information present at website.

## Expected Outcomes
Help bot that can be integrated to web

## Potential Impact
- Self-service support
- Improved satellite data learning and acceptance
- Reduced human intervention through automated responses to routine queries
- Enabling proactive problem solving with enhanced user experience
